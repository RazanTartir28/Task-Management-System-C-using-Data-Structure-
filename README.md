# Task Management System in C

A console-based Task Management System implemented in C using fundamental data structures including Linked Lists, Stacks, and Queues.

## Features

The system allows the user to:

- Load tasks from a file
- Add a new task
- Delete a task
- Search for a task by ID or name
- View unperformed tasks
- Mark a task as performed
- Undo the last performed task
- View performed tasks
- Generate a summary report

## Data Structures Used

### Linked List
Used to store and manage unperformed tasks dynamically.

### Stack
Used to store performed tasks. This allows the most recently performed task to be accessed first.

### Queue
Used to keep track of tasks that have been undone.

## Task Information

Each task contains:

- Task ID
- Task Name
- Task Date
- Task Duration

Tasks in `tasks.txt` use the following format:

ID#TaskName#Date#Duration

Example:

1#Complete Data Structures Assignment#10/5/2025#2.5

## Files

- `task_management.c` - Main C source code.
- `tasks.txt` - Sample input tasks.
- `Report.txt` - Generated by the program when the summary report option is selected.

## Compile

Using GCC:

gcc task_management.c -o task_management

## Run

On Windows:

task_management.exe

On Linux/macOS:

./task_management

Make sure `tasks.txt` is located in the same directory as the program.

## Menu Options

1. Load Tasks File
2. Add a New Task
3. Delete a Task
4. Search for a Task
5. View Unperformed Tasks
6. Perform a Task
7. Undo Last Performed Task
8. View Performed Tasks
9. Generate a Summary Report
10. Exit
